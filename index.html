プライバシーポリシー

RF Design Studio
最終更新日: 2026年11月21日

1. このポリシーの対象

このプライバシーポリシーは、Morita Shigeki（以下「開発者」）が提供する Android アプリ「RF Design Studio」（パッケージ名 com.atakmap.android.rfdesignstudio.plugin、ATAK CIV 用プラグイン）に適用されます。

本アプリは、利用者が別途インストールした ATAK CIV の中で動作し、地図上のマーカーを無線局またはレーダー局として、電界、見通し、局間の伝播損失を端末上で検討するためのツールです。

2. 開発者

  • 氏名: Morita Shigeki
  • 連絡先: shigeki7299@gmail.com

プライバシーに関する問い合わせは、上記メールアドレスで受け付けます。

3. 開発者が取得しない情報

開発者は、本アプリ専用のサーバを運営しません。次の情報を、開発者のサーバへ送信、保存、販売することはありません。

  • アカウント、氏名、メールアドレス、電話番号
  • 広告 ID、解析用の利用状況、クラッシュレポート
  • 決済情報
  • 写真、マイク、連絡先アプリ、SMS

本アプリには、広告 SDK、解析 SDK、クラッシュレポート SDK、ログイン機能、アプリ内課金はありません。

4. 端末上で扱う情報

計算と表示のため、本アプリは ATAK がすでに保持している地図マーカーと、利用者が入力した無線諸元を、その端末の中だけで読み書きします。

  • マーカーの識別子（UID）、コールサイン、表示名
  • マーカーの緯度・経度。自局マーカーを選んだ場合は、その端末の地図上の位置を含みます
  • 無線・レーダーの諸元（周波数、電力、アンテナ高、利得、損失、ビーム幅、RCS、対象高度、表示色など）
  • 対向通信と評定図の計算結果、プラグインの表示設定

これらは ATAK の端末内設定、および利用者が保存または送信準備をしたマーカーの添付情報として残ります。Android のアプリデータ自動バックアップは無効です。標高（DEM）は伝播計算に使い、開発者へは送りません。

5. 利用目的

  • 電界図、局間リンク、対向通信、評定図の計算と表示
  • 利用者が保存した計算条件を、同じ端末で次回も使えるようにすること
  • 利用者が SEND を実行したとき、選んだ ATAK の連絡先へ局情報を渡すこと

6. 端末の外へ出る場合

局情報、コールサイン、座標が端末の外へ出るのは、利用者が SEND を実行し、ATAK の連絡先または利用者が設定済みの TAK ネットワークへ送るときです。送信先は利用者が選びます。開発者はその通信を受信せず、中継せず、保管しません。

通信路の保護は、利用者が ATAK に設定した接続に従います。開発者は TAK サーバを提供しません。

7. 権限

本プラグインは、位置情報、連絡先、写真、マイクなどの危険な権限を独自には宣言しません。地図とマーカーの位置は、ホストである ATAK を通じて参照します。

8. 保存期間と削除

開発者は上記データの写しを持ちません。端末内のデータは、アプリ内の削除、ATAK のストレージ消去、または本プラグインのアンインストールで消えます。

開示、訂正、削除の請求先は第2項のメールです。開発者が保有する個人データがない場合は、その旨を回答します。

9. 子ども

本アプリは子どもを対象にしていません。想定する利用者は 18 歳以上です。

10. 変更

本ポリシーを変更するときは、このページの内容と最終更新日を更新します。変更後のポリシーは、このページに掲載したときから適用されます。

1. Scope

This privacy policy applies to the Android app “RF Design Studio” (package com.atakmap.android.rfdesignstudio.plugin), an ATAK CIV plugin provided by Morita Shigeki (“developer”). The app runs inside ATAK CIV, which the user installs separately, and calculates radio coverage, line of sight, and path loss for map markers on the device.

2. Developer

  • Name: Morita Shigeki
  • Contact: shigeki7299@gmail.com

Privacy questions can be sent to that address.

3. Data the developer does not receive

The developer does not operate a server for this app and does not transmit, store, or sell accounts, names, email addresses, phone numbers, advertising IDs, analytics, crash reports, payment data, photos, microphone audio, address-book contacts, or SMS. The app has no advertising SDK, analytics SDK, crash-reporting SDK, sign-in, or in-app purchases.

4. Data handled on the device

To calculate and display results, the app reads and writes, on that device only, map markers already held by ATAK and the radio parameters the user enters:

  • Marker UID, callsign, and label
  • Marker latitude and longitude, which can include the device position on the map when the user selects their own marker
  • Radio and radar parameters such as frequency, power, antenna height, gain, loss, beamwidth, RCS, target altitude, and display colors
  • Point-to-point and rating results, and plugin display settings

This information stays in ATAK preferences on the device and in marker attachments the user saves or prepares to send. Android automatic backup is disabled for the app. Elevation data is used for the calculation and is not sent to the developer.

5. Purposes

  • Coverage, link, point-to-point, and rating calculations and display
  • Keeping the user’s saved parameters available on the same device
  • Passing station information to ATAK contacts when the user runs SEND

6. When data leaves the device

Station information, callsigns, and coordinates leave the device only when the user runs SEND and ATAK delivers them to contacts or to a TAK network the user has already configured. The user chooses the destination. The developer does not receive, relay, or store that traffic. Protection in transit follows the ATAK connection the user configured. The developer does not provide a TAK server.

7. Permissions

This plugin does not declare its own dangerous permissions for location, contacts, photos, or the microphone. It reads map markers through the ATAK host.

8. Retention and deletion

The developer keeps no copy of this data. On-device data is removed when the user deletes it in the app, clears ATAK storage, or uninstalls the plugin. Requests for access, correction, or deletion can be sent to the email in section 2. If the developer holds no personal data, the reply will say so.

9. Children

The app is not directed at children. It is intended for users aged 18 and over.

10. Changes

Updates to this policy are posted on this page with a new “Last updated” date and apply from the time they are posted.
