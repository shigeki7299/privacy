プライバシーポリシー

LineChecker
最終更新日: 2026年11月21日

1. このポリシーの対象

このプライバシーポリシーは、Morita Shigeki（以下「開発者」）が提供する Android アプリ「LineChecker」（パッケージ名 com.infinityengine.linechecker）に適用されます。

本アプリは、利用者が指定した相手との回線測定、通信アダプタの状態表示、同一 LAN 内の端末表示、USB シリアル通信を行うツールです。

2. 開発者

  • 氏名: Morita Shigeki
  • 連絡先: shigeki7299@gmail.com

プライバシーに関する問い合わせは、上記メールアドレスで受け付けます。

3. 端末上で扱う情報

測定と表示のため、本アプリは次の情報をその端末の中で読み書きします。開発者のサーバへは送りません。

  • 利用者が入力した測定先ホスト、ポート、測定時間
  • この端末の IP アドレス、Wi-Fi のネットワーク名（SSID）、アクセスポイント識別子（BSSID）、電波強度、周波数、リンク速度
  • 携帯電話網の事業者名、通信世代（5G、LTE など）、データ通信のオン／オフ、SIM の有無。電話番号と IMEI は読みません
  • Bluetooth アダプタの名前とオン／オフ、Ethernet と VPN の有無と IP アドレス
  • LAN スキャンで見つかった機器の IP アドレス、MAC アドレス、メーカー名（端末内の一覧で照合）、応答の種類
  • USB シリアルの通信設定と、利用者が接続した機器との送受信内容

位置情報の権限は、Android が Wi-Fi のネットワーク名と BSSID の表示に求めるため使います。GPS の移動履歴は記録しません。LAN スキャンの結果は画面表示用で、測定設定とシリアル設定だけを端末内に保存します。Android のバックアップが有効なため、その設定が利用者の Google アカウントのバックアップに含まれることがあります。開発者はそのバックアップを受け取りません。

4. 端末の外へ出る通信

  • スループット測定の試験通信は、利用者が入力したホストとポートへ送られます
  • LAN スキャンの探索パケットは、接続中のローカルネットワーク内に留まります
  • シリアル通信の内容は、利用者が接続した USB 機器との間でやり取りされます

これらは利用者が選んだ相手との通信です。開発者はその内容を受信せず、保管しません。

5. 広告

メイン画面に Google AdMob のバナー広告を表示します。広告の配信、効果測定、不正防止のため、Google LLC が広告 ID、IP アドレス、端末情報、広告の操作、おおよその位置情報を処理することがあります。開発者はこの情報を販売しません。

Google の取り扱いは Google プライバシーポリシー と AdMob のデータ取り扱い に従います。

6. 保存期間と削除

測定先やシリアル設定は、利用者がアプリのデータを消去するか、アプリをアンインストールするまで端末内に残ります。開発者は測定結果、LAN スキャン結果、シリアル通信の写しを持ちません。開示、訂正、削除の請求先は第2項のメールです。開発者が保有する個人データがない場合は、その旨を回答します。広告に関する Google 側のデータは、Google の手続きに従います。

7. 子ども

本アプリは子どもを対象にしていません。広告を含むため、子ども向けサービスとしては提供しません。想定する利用者は 18 歳以上です。

8. 変更

本ポリシーを変更するときは、このページの内容と最終更新日を更新します。変更後のポリシーは、このページに掲載したときから適用されます。

Privacy Policy

日本語 · English

LineChecker
Last updated: 21 November 2026

1. Scope

This privacy policy applies to the Android app “LineChecker” (package com.infinityengine.linechecker) provided by Morita Shigeki (“developer”). The app measures a link to a host the user enters, shows adapter status, lists devices on the same LAN, and provides a USB serial terminal.

2. Developer

  • Name: Morita Shigeki
  • Contact: shigeki7299@gmail.com

Privacy questions can be sent to that address.

3. Data handled on the device

For measurement and display, the app reads and writes the following on that device. It does not send this data to a server operated by the developer.

  • The host, port, and duration the user enters
  • This device’s IP address, Wi-Fi SSID, BSSID, signal strength, frequency, and link speed
  • Mobile operator name, network generation (such as 5G or LTE), whether mobile data is on, and whether a SIM is present. The app does not read the phone number or IMEI
  • Bluetooth adapter name and on/off state, and Ethernet or VPN presence and IP address
  • IP address, MAC address, vendor name from a list stored in the app, and response type for devices found by a LAN scan
  • USB serial settings and the bytes exchanged with the device the user connects

The location permission is used because Android requires it to display the Wi-Fi name and BSSID. The app does not record a GPS track. LAN scan results are shown on screen. The app saves measurement and serial settings on the device. Android backup is enabled, so those settings may be included in the user’s Google account backup. The developer does not receive that backup.

4. Data that leaves the device

  • Throughput test traffic is sent to the host and port the user enters
  • LAN scan packets stay on the local network the device is connected to
  • Serial data is exchanged with the USB device the user connects

These transfers go to a destination the user chooses. The developer does not receive or store them.

5. Advertising

The main screen shows a Google AdMob banner. For ad delivery, measurement, and fraud prevention, Google LLC may process the advertising ID, IP address, device information, ad interactions, and approximate location. The developer does not sell this information.

Google’s handling is described in the Google Privacy Policy and AdMob data disclosure.

6. Retention and deletion

Measurement and serial settings remain on the device until the user clears the app’s data or uninstalls it. The developer keeps no copy of test results, LAN scan results, or serial traffic. Requests for access, correction, or deletion can be sent to the email in section 2. If the developer holds no personal data, the reply will say so. Data held by Google for advertising follows Google’s own process.

7. Children

The app is not directed at children. Because it shows ads, it is not offered as a child-directed service. It is intended for users aged 18 and over.

8. Changes

Updates to this policy are posted on this page with a new “Last updated” date and apply from the time they are posted.
